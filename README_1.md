# 생각 기록 20일

20일 달력에서 하루 한 장면을 골라 8단계로 적는 생각 기록 페이지입니다.
앞 일차를 완료하면 다음 일차가 열리고, 각 일차는 한 화면에서 위에서 아래로 이어서 적습니다.

1. 상황
2. 신체 반응
3. 감정 관찰 (빨강·노랑·파랑·초록 네 가지 색에서 세부 감정 선택)
4. 생각 관찰 (스친 생각, 자동적 생각 6가지, 인지 오류 11가지, 다르게 생각해 보기)
5. 이해
6. 욕구
7. 다음 행동 (추천 행동 선택, 직접 적기, 언제까지 무엇을 몇 번 할지 계획)
8. 점검

각 일차 맨 아래 **나눔 카드**에서 원하는 단계만 골라 글로 복사해 그룹 채팅방에 올릴 수 있습니다.

파일은 `index.html` 하나뿐이며 서버나 빌드 과정이 필요 없습니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다. 무료 계정은 저장소가 Public이어야 Pages를 쓸 수 있습니다.
2. **Add file → Upload files**에서 `index.html`과 `README.md`를 올리고 **Commit changes**를 누릅니다.
3. 저장소의 **Settings → Pages**로 갑니다.
4. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소로 열립니다.

## 휴대폰에서 앱처럼 쓰기

- 아이폰: Safari로 주소를 열고 공유 버튼 → **홈 화면에 추가**
- 안드로이드: Chrome으로 주소를 열고 ⋮ 메뉴 → **홈 화면에 추가**

아이폰은 Safari에서 쓴 기록과 홈 화면 아이콘으로 연 기록이 따로 저장됩니다. 홈 화면에 추가한 뒤 그 아이콘으로 첫 기록을 시작하세요.

## 기록 보관

- 기록은 쓰는 사람의 기기, 그 브라우저 안에만 저장됩니다. 어디로도 전송되지 않으며 페이지를 만든 사람도 볼 수 없습니다.
- 브라우저 데이터를 지우거나 기기·브라우저를 바꾸면 기록이 보이지 않습니다. 페이지 주소가 바뀌어도 마찬가지입니다.
- 달력 아래 **백업 파일 내려받기**로 파일을 저장해 두고, 다른 기기에서는 **백업 파일 불러오기**로 옮길 수 있습니다. 불러오면 그 브라우저의 기록이 백업 내용으로 바뀝니다.

## 고칠 때

저장소에서 **Add file → Upload files**로 새 `index.html`을 같은 이름으로 올리면 덮어써집니다. 주소가 같으면 각자의 기록은 그대로 남습니다.

## 안내

자기 관찰을 돕는 심리교육용 도구입니다. 상담이나 치료를 대신하지 않습니다.
